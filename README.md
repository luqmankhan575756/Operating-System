# Operating-System

## 📚 Course Overview

This repository contains my **Operating Systems** course work, including concepts, practical tasks, assignments, and programming exercises related to operating systems.

The main purpose of this repository is to understand how an operating system manages **processes, memory, files, CPU resources, and hardware** and how these concepts are implemented in practice.

---

## 🎯 Course Objectives

The main objectives of this course are:

* Understand the fundamental concepts of Operating Systems.
* Learn how processes and threads work.
* Understand CPU scheduling algorithms.
* Study process synchronization and communication.
* Understand deadlocks and their prevention.
* Learn memory management techniques.
* Understand virtual memory and paging.
* Study file systems and disk management.
* Understand input/output management.
* Learn basic concepts of system calls and operating-system architecture.

---

## 📖 Topics Covered.

### 1. Introduction to Operating Systems

* What is an Operating System?
* Functions of an Operating System
* Types of Operating Systems
* OS Services
* System Calls
* Operating System Structures

### 2. Process Management

* Process Concept
* Process States
* Process Control Block (PCB)
* Process Scheduling
* Context Switching
* Process Creation and Termination

### 3. Threads

* What is a Thread?
* Single-threaded and Multithreaded Processes
* User-Level Threads
* Kernel-Level Threads
* Multithreading Models

### 4. CPU Scheduling

* First Come First Serve (FCFS)
* Shortest Job First (SJF)
* Shortest Remaining Time First (SRTF)
* Priority Scheduling
* Round Robin
* Multilevel Queue
* Multilevel Feedback Queue

### 5. Process Synchronization

* Race Conditions
* Critical Section
* Mutex
* Semaphores
* Monitors
* Producer-Consumer Problem
* Readers-Writers Problem
* Dining Philosophers Problem

### 6. Deadlocks.

* Deadlock Conditions
* Deadlock Prevention
* Deadlock Avoidance
* Banker's Algorithm
* Deadlock Detection
* Deadlock Recovery

### 7. Memory Management

* Memory Allocation
* Contiguous Memory Allocation
* Paging
* Segmentation
* Page Tables
* Fragmentation

### 8. Virtual Memory

* Demand Paging
* Page Faults
* Page Replacement
* FIFO
* Optimal Page Replacement
* LRU

### 9. File Systems

* File Concepts
* File Attributes
* File Operations
* Directory Structures
* File Allocation Methods
* Free Space Management

### 10. Disk Management

* Disk Scheduling
* FCFS
* SSTF
* SCAN
* C-SCAN
* LOOK
* C-LOOK
